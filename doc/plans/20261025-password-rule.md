# パスワードの規則を8文字以上に揃える

## 目的

本番の新規登録で、画面は「8文字以上」と案内しているのに、送信すると12文字以上を求められた。
本番の規則（12文字以上、大小の英字、数字、記号、流出済みでないこと）は最初のコミットでスターターキットから引き継いだもので、意図して決めたものではない。
開発環境には規則が無く、本番に出すまで食い違いに気づかなかった。

## 決めたこと

全環境で8文字以上とし、本番だけ流出済みパスワードを弾く。
画面の表示（新規登録、ログイン、パスワード再設定、設定）は変えない。

ペルソナと要件は「わかりやすさ、使い心地」を求めており、記号まで必須の12文字は登録でつまずく原因になる。
流出済みかどうかの確認は NIST SP 800-63B でも重視されており、文字種の強制より効果がある。
流出の確認を本番に限るのは、テストで外部に問い合わせないためである。

## 採らなかった案

**本番の規則に揃え、画面の表示を書き換える。** 安全側だが、上の理由で使い心地を損なう。
