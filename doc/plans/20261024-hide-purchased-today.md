# 購入済みにしたストックを購入予定品から外す

## 背景

ダッシュボードの「買った」を押すと、次回購入予定日が「今日 + 消費日数 × ストック数」に進む。
この日数が7日以内だと、押したあとも購入予定品（1週間以内）に残る。
同じ日にもう一度押しても同じ日付になるので、利用者には押しても反映されないように見える。

## 決めたこと（2026-10-24）

- 購入済みにした日を `stocks.last_purchased_on`（date、NULL可）に記録する
- 購入日から次回購入予定日までが7日以内のものは、予定日の前日まで購入予定品から外す（当日から出す）。件数（1週間以内）も同じ範囲で数える
- 7日を超えるものは今までどおり予定日の1週間前から出す
- カレンダーと次回購入日は今までどおり全件を見る
- ストックを編集したら `last_purchased_on` を消し、通常の表示に戻す

## 採らなかった案

- **予定日の前日まで一律に外す**：決まりは単純だが、周期の長いものも当日まで出なくなり、1週間前に知らせる働きがなくなる
- **押したらトーストで結果を知らせるだけにする**：押したことは伝わるが、一覧に残り続けるので誤解は消えない
- **今日押したものはボタンを押せなくする**：一覧に残る点は変わらない

## 変更

| 対象 | 内容 |
|---|---|
| マイグレーション | `stocks.last_purchased_on` を追加 |
| `StockController` | `purchase` で今日を入れる。`update` で NULL に戻す |
| `pages/dashboard.tsx` | 購入予定品の絞り込みに上の条件を足す |
| 要件定義書、設計書 | ダッシュボードとデータ設計の記述を直す |
